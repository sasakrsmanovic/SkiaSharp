Version 3.119.1

Bugfix & maintenance release · Released September 23, 2025 · NuGet

Highlights

A stability-focused release that fixes several crashes and platform-specific issues. Metal rendering on Apple platforms received the most attention — double-initialization and iOS 15 compatibility are both resolved. Windows users benefit from a fix for WinUI loading in unpackaged apps, and a new PostScriptName property lands on SKTypeface. Four community contributors drove the majority of the user-facing fixes.

Breaking Changes

None in this release.

New Features

API Surface

  • SKTypeface.PostScriptName — Exposes the PostScript name of a typeface, useful for font embedding and PDF workflows. ❤️ @jonlipsky (#3263)

Security

  • zlib updated to v1.3.0.1+ — Picks up upstream security and stability fixes. (#3058)

Bug Fixes

  • SKMetalView no longer initializes twice — Prevents redundant Metal setup that could cause rendering issues on Apple platforms. ❤️ @jeremy-visionaid (#3256)
  • Metal hotfix for iOS 15 and lower — Restores Metal rendering compatibility on older iOS versions. ❤️ @taublast (#3293)
  • SKAutoCanvasRestore no longer crashes on Dispose — Safely handles the case where the underlying canvas was already disposed. ❤️ @taublast (#3291)
  • SKXamlCanvas transparency on Mac Catalyst — The canvas is no longer incorrectly marked as opaque, fixing rendering with transparent backgrounds. ❤️ @spouliot (#3236)
  • PDF DateTime conversion fix — SKDocumentPdfMetadata now correctly converts UTC DateTime values. ❤️ @jeremy-visionaid (#3333)
  • WinUI unpackaged app loading — EGL is now built as Win32 and GLESv2 as WASDK, fixing native library loading in unpackaged WinUI 3 apps. (#3338)
  • WinUI interop built with /MT — Eliminates the Visual C++ runtime dependency for the WinUI interop library. (#3341)
