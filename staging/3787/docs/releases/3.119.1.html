Version 3.119.1

Bug fix & stability release · Released September 23, 2025 · NuGet · GitHub Release

Highlights

This release fixes several crashes and rendering issues across Apple and Windows platforms, adds the PostScriptName property to SKTypeface, and updates zlib to address security vulnerabilities. Five community contributors drove the majority of user-facing changes in this release.

Breaking Changes

None in this release.

New Features

API Surface

  • PostScriptName on SKTypeface — Exposes the PostScript name of the typeface, making it easier to identify and match fonts programmatically. ❤️ @jonlipsky (#3263)

Security

  • Update zlib to v1.3.0.1+ — Bumps the bundled zlib to pick up upstream security fixes. (#3058)

Bug Fixes

  • Avoid initializing SKMetalView twice — Prevents a double-initialization that could cause rendering issues on Apple platforms. ❤️ @jeremy-visionaid (#3256)
  • SKAutoCanvasRestore crash on disposed canvas — Prevents a crash when Dispose is called after the underlying canvas has already been disposed. ❤️ @taublast (#3291)
  • SKXamlCanvas opaque on Mac Catalyst — Fixes the XAML canvas being incorrectly opaque on Mac Catalyst, which blocked content behind it from showing through. ❤️ @spouliot (#3236)
  • Metal crash on iOS 15 and lower — Fixes a Metal rendering crash on older iOS versions. ❤️ @taublast (#3293)
  • UTC DateTime conversion for SKDocumentPdfMetadata — Corrects timezone handling when setting PDF document metadata dates. ❤️ @jeremy-visionaid (#3333)
  • Unpackaged WinUI loading issues — Builds EGL as Win32 and GLESv2 as WASDK to fix native library loading failures in unpackaged WinUI apps. (#3338)
  • WinUI Interop built as /MT — Switches the WinUI interop library to static CRT linking, eliminating runtime dependency issues. (#3341)
